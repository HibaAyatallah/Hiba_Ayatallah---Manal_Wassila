Le seuil d'incertitude de 60 % permet de garder l'automatisation pour les avis clairs tout en renvoyant les cas ambigus vers un agent humain. Ce compromis évite de classer trop brutalement les avis mitigés, qui sont précisément ceux où le modèle a le moins de confiance. Le résultat est un meilleur équilibre entre efficacité opérationnelle et fiabilité métier, sans bloquer toute l'automatisation sur des commentaires à risque.
